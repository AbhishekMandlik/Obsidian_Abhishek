
Old Formula
```
Priority Score = (Sensing) + (Forecast • 1.5) + (Availaibility) - (Integration Cost • 1.2)
Problems:
1. Sensing is irrelevant for forecasting scope.
2. No Lead time dimension.
3. Correlation and causation conflated.
```


### New Formula
```
Priority Score = (Signal Strength • 1.5) + (Lead Time Utility • 2) + (Causal Directness • 1.0) +(Availability) - (Integration Cost • 1.2)
```

> Score Thresholds
> TOP: ≥18
> Medium: 11-17
> Low: 5-10
> GTH: <5
