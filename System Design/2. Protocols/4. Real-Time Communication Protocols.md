Continuous Exchange of data with minimal latency.
Traditional HTTP designed around a simple request-response cycle, which works well for fetching data but not for continuous information.
Alternatives to improve real-time data exchange:
1. Polling: Simple but generates unnecessary requests.
2. WebSockets: Persistent 2 way connection.
3. SSE: continuous updates pushing in one direction.
4. Long Polling: Keeps polls open for a longer duration.

### WebSockets: Persistent Full-Duplex Communication:
Definition: WebSockets provide a persistent, full duplex connection between the client and server over a single TCP connection.
Working:
1. WebSocket handshake using HTTP upgrade request.
	1. Client requests a webSocket connection.
	2. Server accepts and keeps the connection open. (Protocol Switch)
2. Connection Open: single long TCP connection.
3. Data exchange in real time using frames.
4. Either party can close the connection when done.
### Advantages and use cases of WebSockets
Advantages
1. Persistent connection=lower latency
2. Reduces overhead compared to HTTP polling. Instead of users asking multiple queries and receiving no useful information webSockets will push the data as and when any event occurs.
3. Efficient for real-time application.

### Long Polling: Simulating Real-Time with HTTP:
Definition: A technique where the client sends a request to the server and waits until the server has new data to respond with.
Instead of immediate responses, the server holds the request until new data is available.
How it works:
1. Client makes a request.
2. Request added to a queue and server holds it until any new information is available.
3. Server responds with a new data and then client again sends a request.
This approach significantly reduces unnecessary traffic because the server responds only when their is something worth sending.
It is built on HTTP so every update requires a new request response cycle which means new connection setup and teardown.

### When to Use WebSockets vs. Long Polling?
1. WebSockets: High frequency, bi-directional, low latency.
2. Long Polling: WebSockets are not supported or are overkill, periodic updates are sufficient. (Notification or IoT devices).
