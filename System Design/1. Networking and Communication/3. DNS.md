Domain Name System
It is phonebook of the internet. IP addresses can keep on changing which can reduce the accessibility of websites. It supports distributed, scalable internet architecture.

Before a browser can connect to a server, it must first discover where that server lives, and without it web would be much less scalable.

DNS is hierarchical server,
### Types of DNS servers
1. Root Name Servers: Top-level servers handling... like .com, .org.
2. TLD Name servers: Specific to domains .ai, .net etc.
3. Authoritative Name Servers: Store domain-specific records.
4. Recursive Resolvers: Handle queries on behalf of users, contacting multiple DNS servers if necessary.
This makes DNS scalable.


### DNS Caching and Performance Optimisation.
- Reduces latency.
- Reduce load on DNS servers.

Caching occurs:
1. Browser cache.
2. OS Cache.
3. Recursive resolver cache.

TTL determines how long a cache is valid.

### Domain Name Resolution Process
1. Browser cache check.
2. OS cache check.
3. Query to local DNS Resolver.
4. If not found query goes to Root DNS server
5. TLD(Top-Level Domain) These servers provide Authoritative DNS server details.
6. It returns IP address.
7. Response cache is return to the user. 

### Importance in Large-Scale Systems
1. Ensuring High Availability:
	1. Load Balancing using DNS
	2. Any-cast DNS for faster global resolution
2. DNS Failover Strategies:
	1. Primary and secondary DNS servers
3. Content Delivery Networks:
	1. How DNS directs users to the nearest CDN node for fast loading?
4. DNS Security Risks:
	1. DNS poisoning.
	2. Cache poisoning.
	3. DDoS attacks.
	4. AnyCast layer for protection.
