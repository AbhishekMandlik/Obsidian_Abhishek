IP- Internet Protocol... It is the internet addresses. Used for communication between different machines, server and services across the internet.
Primary Versions:
- IPv4
- IPv6
Primary Categories:
- Public
- Private

IPv4: 32 bit address format --- 4.3 billion unique addresses.
- 192.168.1.1

IPv6 128-bit address. Designed for IoT, mobile networks and future scalability.
- Improve routing efficiency
- Better Security

| Feature                | IPv4                               | IPv6                                       |
| ---------------------- | ---------------------------------- | ------------------------------------------ |
| **Address Size**       | 32-bit                             | 128-bit                                    |
| **Address Space**      | ~4.3 billion addresses             | ~3.4 x 10³⁸ addresses                      |
| **Notation**           | Dotted-decimal (e.g., 192.168.1.1) | Hexadecimal with colons (e.g., 2001:db8::) |
| **Header Size**        | Variable (20–60 bytes)             | Fixed (40 bytes)                           |
| **Security**           | Optional IPsec                     | Built-in IPsec support                     |
| **Configuration**      | Manual or DHCP                     | Stateless Auto-configuration (SLAAC)       |
| **Transmission Types** | Unicast, Broadcast, Multicast      | Unicast, Multicast, Anycast                |
| **Checksum Field**     | Yes                                | No (removed for faster processing)         |

### Private vs Public IPs
Public IPs:
- Assigned by ISPs.
- Used to communicate over the internet.
- Unique worldwide.
Private IPs:
- Local Networks.
- Cant be accessed directly from the internet.

Key take away both are required for accessibility, scalability and security.

Private required for:
- Conserves public IP addresses.
- Enhance Security, as they are not routable over the internet
- Enables Network Address Translation to allow multiple device to share a single public IP.
- Common in corporate network, DC and cloud.
- They reduce attack surface, building secure distributed systems.


Role of IPs in system Design.
- Scalability: Helps in designing distributed, multi-region and cloud based architecture.
- Security: Enables Firewall rules, VPNs and private networking
- Load Balancing, IP based traffic.
- Cloud Networking: Public, Private hybrid cloud IP management.
- Microservices and Containers: Use internal IPs for communication
