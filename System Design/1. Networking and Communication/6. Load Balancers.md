Modern applications must handle growing traffic as it ensures that a single server does not become a bottleneck. It is foundational building block of distributed systems. Horizontal scaling is made possible.

### The scaling challenge
- Server resources are finite.
- Growing traffic increases latency and failures.
- Larger servers help only temporarily.
- Vertical scaling eventually reaches a limit.

### Horizontal Scaling Creates a New Problem
- Capacity grows by adding servers.
- Workload can be shared across machines.
- Users should not choose servers manually.
- Traffic now needs a distribution mechanism.

### Load Balancer
 It is the systems entry point. Incoming requests are distributed across servers, Traffic is no longer on a single machine. Applications can scale more effectively. Capacity grows while User experience remains unchanged. 

#### It enables reliable systems
Multiple servers provide redundancy, Failed servers can be bypassed, maintenance becomes safer availability and resilience improve
