### What is a proxy?
It is an intermediary server between a client and another server. They help with security, caching, traffic control, and anonymity.
Two main types forward and reverse proxy.
### Forward Proxy:
Sits between client and internet
- Client connects to the forward proxy instead of directly accessing the websites.
- Can filter content, provide anonymity and cache requests.
- Common use-cases:
	- Bypassing geo-restrictions.
	- Anonymous browsing.
	- Caching webpages for faster access.
### Reverse Proxy:
Sits between users and backend servers.
- Clients don't directly communicated with backend servers-requests go through the reverse proxy.
- Used for load balancing, caching, security, and SSL termination.
- Common use cases:
	- Load balancing across multiple servers
	- Caching content to improve speed
	- DDoS protection and security
