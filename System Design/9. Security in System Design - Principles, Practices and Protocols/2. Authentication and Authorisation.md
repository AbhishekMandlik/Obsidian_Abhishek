1. Authentication: Verifying who the user is(identity verification).
2. Authorisation: Granting the user permission to access specific resources based on their identity.
3. Key difference: Authentication is about who you are, while authorisation is about what you can do.

### Common Authentication Methods
1. Basic Authentication: Simple user and password-based authentication.
2. OAuth2: Delegated access protocol, allowing third-party services to access user data without exposing credentials.
3. OpenID Connect: An identity layer built on top of OAuth2 for authentication, often used for single sign-on(SSO).
4. JWT (JSON Web Tokens): Token-based authentication, commonly used in stateless applications and APIs.

### Session-based vs Token-based Authentication
- Session-based Authentication:
	- Server-side storage of session data, typically using cookies.
	- Pros: Easy to implement, works well with traditional web applications.
	- Cons: Scalability challenges in distributed systems.
- Token-based Authentication: 
	- Stateless, where tokens(JWT) are used to authenticate the user.
	- Pros: Scalable, decouples backend systems, like micro-service and modern distributed systems for service scalability.
	- Cons: Requires secure token storage and handling.

### Access Control Models
- RBAC(Role-Based Access Control): Assigns permissions based on user roles.
	- Simpler to manage but less flexible.
- ABAC(Attribute Based Access Control): Grants access based on attributes(department, project).
	- More fine-grained but more complex.
- DAC (Discretionary Access Control): Owner of a resource defines access controls.
- MAC (Mandatory Access Control): Access Control decisions are made by a central authority based on security policy.

### SSO(Single Sign-On) and Identity Federation
- SSO: A user authentication process that allows a user to access multiple applications with a single set of credentials.
	- Benefits: User Convenience, reduced password fatigue.
- Identity Federation: A system where multiple identity providers can be used to authenticate users across different platforms.
	- Benefits: Seamless user experience across different services, reduces need for creating multiple accounts.
