System Design Interview Question Answer Format:
1. Understanding the Problem and Identifying the scope
	1. Functional Requirements: (Intent of the problem)
	2. Non Functional Requirements: (Availability, Reliability, Scalability and Performance)
	3. Working Strategies of the problems and which one to choose.
2. Identifying the Bottlenecks
	1. Read/ Write Heavy System?
	2. Latency Sensitivity.
	3. Plan for Burst traffic: CDN, Cache and Load Balancers.
3. High- Level Design: Services, APIs and Communication
	1. Core Components.
	2. Backend and Frontend Services.
	3. API Designs.
	4. Collisions Handler.
	5. High Level Design:(API Gateway, Main Service logic, Cache, Database, Authentication Service, Redirection(HTTP 302))
4. Making Tech and Infra Decisions.
	1. DB: SQL, No SQL, Cache(memory caching).
	2. Scalability: Horizontal Scaling.
	3. High Availability: Load Balancer, Replication, Failover.
5. The Final Design
	Present the final Design
