Applications need to exchange and store structured data efficiently. Serialisation converts complex objects into a format that can be easily transferred. Used in APIs, DB, caching and distributed systems.

```
Object->Stream of bits-> File/DB/Memory -> Stream of Bits -> Object

    Serialisation                             De-serialisation
Building scalable systems that are reliable as serialisation is used everywhere to transfer data.
```

Serialisation is mainly making data portable. It converts objects into a format for transmission/ storage. Deserialisation means converting it back into object. It is essential for distributed systems and inter-process communication. It is bridge between application memory and the outside world.

### Common Serialisation Format
1. JSON: Human - readable widely used in REST APIs.
	1. Human-readable, widely used in APIs and web applications.
	2. Simple key-value structure easy to parse.
	3. Text-based so larger in size compared to binary formats.
2. XML: Structured but verbose, used in legacy systems.
	1. Tag-based markup language, used in legacy systems and configuration files.
	2. More complex than JSON, so supports rich data structures.
	3. Verbose, leading to larger payloads
3. Protobuf: Protocol Buffers- Compact and Efficient, used in gRPC.
	1. Binary Format developed by Google.
	2. Faster and smaller than JSON/XML but requires schema definations.
	3. Used in gRPC for high performance APIs.

JSON optimises for simplicity and interoperability, XML for structure and validation and protobuf for performance and scalability.

### Trade-offs: Readability vs. Efficiency vs. Compatibility
1. Readability: JSON and XML are human readable but ineffecient.
2.  Efficiency: Protobuf and Avro are compact both reduce bandwidth usage.
3. Compatibility: XML support schema evolution, JSON has limited support.

### Serialisation in Action:
1. In APIs:
	1. REST APIs mostly use JSON.
	2. gRPC APIs use prototbu for efficiency
	3. XML is used in SOAP-based web services and legacy codebases only.
2. In Caching and Data Storage:
	1. Redis and Memcached: Store serialised JSON/Protobuf Data.
